# ClassTutor — CBSE Standard 5 AI Tutor for Rishit

An interactive, voice-enabled AI audio tutor for CBSE Standard 5 students.

- Works 100% in the cloud on iPhone Safari / Chrome.
- Direct Google Gemini API with Lite-first model sequence (`gemini-2.5-flash-lite`).
- Dynamic search across 1,010 textbook pages with zero hallucination.
- Dual citations: Split-screen PDF viewer + Google Drive links.
